====================================================================
 RBX FAMILY MANAGER - DEPLOY ON WISPBYTE (free, no credit card)
====================================================================

Takes ~5 minutes. The free plan is 512 MB RAM / 1 GB disk / no card,
and you only need to log in to the panel every 2 weeks to keep it.

STEP 1 - Create the server
--------------------------
* Go to https://wispbyte.com -> Sign Up (email only, no card).
* Log in at https://wispbyte.com/client.
* Create Server -> Name: "RBX Family Manager".
* Docker image: PYTHON. Database attachment: none (the bot uses
  SQLite, which is just a file in the server folder).

STEP 2 - Connect GitHub
-----------------------
* Open the server -> GitHub in the sidebar (under General).
* Connect your GitHub account and pick this repository.
* Pull -> the bot code lands on the server automatically.
  From now on: push to GitHub, then press Pull in the panel.

STEP 3 - Token
--------------
* Open STARTUP in the sidebar.
* Under Environment Variables add:
      DISCORD_TOKEN = (your bot token from the Discord Developer Portal)
* Main file: bot.py
* No .env upload needed - panel variables are read automatically.

STEP 4 - cookies.txt (needed for /play)
---------------------------------------
No uploading in the Files tab needed anymore:
* Export cookies from your browser on youtube.com with the
  "Get cookies.txt LOCALLY" extension.
* In Discord, run:  /owner cookies file:   and attach the file.
  The bot saves it itself. Done.

STEP 5 - Start
--------------
* Click Start and watch the Console. Wait for:
      "Synced <N> global command(s)."
      "Logged in as RBX Family Manager"
* In Discord type / - every command must appear exactly once.
* Test /ping, /join + /play, and /rank.

STEP 6 - Keep it free
---------------------
* Log in to https://wispbyte.com/client at least every 2 weeks
  (put a phone reminder on it) so the server is never suspended.
* Dashboard: the free panel assigns its own port - check the
  port list on the server page before opening the admin
  dashboard in a browser.

SECURITY
--------
* NEVER commit your real .env or put a real token in .env.example.
* If a token ever leaks: Discord Developer Portal -> Bot ->
  Reset Token. Old tokens stop working immediately.
